# Music Download Sources — Reference

## International Sources

### 1. Jamendo
- **URL**: `https://www.jamendo.com/start`
- **Search**: `https://www.jamendo.com/search?q={query}`
- **Formats**: MP3 (320kbps), FLAC (premium), OGG
- **License**: Creative Commons / Free
- **Notes**: Large catalog of indie and CC music. Direct download available.
- **Best for**: Free background music, CC-licensed tracks

### 2. Free Music Archive (FMA)
- **URL**: `https://freemusicarchive.org/`
- **Search**: `https://freemusicarchive.org/search?quicksearch={query}`
- **Formats**: MP3 (320kbps), FLAC
- **License**: CC / Public Domain
- **Notes**: Curated by WFMU. Excellent quality and legal.
- **Best for**: Curated free music collections

### 3. Musopen
- **URL**: `https://musopen.org/`
- **Search**: `https://musopen.org/music/?q={query}`
- **Formats**: MP3, FLAC, MIDI, sheet music
- **License**: Public Domain
- **Notes**: Classical music only. Recordings and compositions are PD.
- **Best for**: Classical music, Beethoven/Mozart/Bach etc.

### 4. NCS (NoCopyrightSounds)
- **URL**: `https://ncs.io/`
- **Search**: `https://ncs.io/music?search={query}`
- **Formats**: MP3 (320kbps)
- **License**: NoCopyrightSounds License (free for YouTube/content)
- **Notes**: Popular electronic/BGM for content creators. YouTube-friendly.
- **Best for**: Video background music, BGM

### 5. SoundCloud
- **URL**: `https://soundcloud.com/`
- **Search**: `https://soundcloud.com/search?q={query}`
- **Formats**: MP3 (varies)
- **License**: Varies by artist
- **Notes**: Many independent artists enable downloads. Check "Download" button.
- **Best for**: Indie, electronic, remix music

### 6. Bandcamp
- **URL**: `https://bandcamp.com/`
- **Search**: `https://bandcamp.com/search?q={query}`
- **Formats**: MP3, FLAC, WAV, AAC
- **License**: Varies; many free tracks marked "name your price" (0$)
- **Notes**: Best for indie/alternative. Filter by "digital" format.
- **Best for**: Indie, rock, experimental, lo-fi

### 7. Internet Archive — Audio Archive
- **URL**: `https://archive.org/details/audio`
- **Search**: `https://archive.org/search?query={query}&mediatype=audio`
- **Formats**: MP3, FLAC, OGG, WAV
- **License**: Public Domain / Creative Commons
- **Notes**: Massive collection of historical recordings, concerts, podcasts.
- **Best for**: Rare/archival audio, old recordings

## China-Friendly Sources

### 8. 音乐下载网 (Hifini)
- **URL**: `https://www.hifini.com/`
- **Search**: Use site search or forum threads
- **Formats**: FLAC, APE, MP3 (320kbps)
- **License**: User uploaded, varies
- **Notes**: Popular Chinese hi-fi music forum. High-quality FLAC common.
- **Best for**: 华语无损音乐, 粤语无损

### 9. CD包音乐
- **URL**: `http://www.cdbao.com/`
- **Search**: Site search
- **Formats**: FLAC, APE, MP3
- **License**: User uploaded
- **Notes**: Long-running Chinese music sharing site.
- **Best for**: 华语专辑无损

### 10. 墨灵音乐
- **URL**: `https://moe.lol/`
- **Search**: `https://moe.lol/search/{query}`
- **Formats**: MP3
- **License**: Varies
- **Notes**: Simple interface, direct download links.
- **Best for**: Quick MP3 downloads

## Search Tips by Source

| Source | Effective Query | Notes |
|--------|----------------|-------|
| Jamendo | Artist name | Genre pages also useful |
| FMA | Artist + tag | Tag-based browsing |
| Musopen | Composer name | Classical only |
| NCS | Song title | BGM-focused |
| SoundCloud | Exact title | Genre filter helps |
| Bandcamp | Artist name | Filter by price=0 |
| Internet Archive | Song/artist + format | Use mediatype=audio filter |
| Hifini | 歌名+歌手 | 无损专区效果最好 |

## Quality Ranking

1. **FLAC / WAV** — Lossless, ~30-100MB per track
2. **MP3 320kbps** — High quality, ~8-12MB per track
3. **MP3 192kbps** — Good quality, ~5-8MB per track
4. **MP3 128kbps** — Standard quality, ~3-5MB per track

Always prioritize FLAC or WAV when the user requests high quality ("无损").
